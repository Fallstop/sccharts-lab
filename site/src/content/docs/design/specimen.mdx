This page shows the building blocks of a chapter with the guide's styles applied. Its running example is the
landing page's chart, `Toggle`: one boolean input, `button`, one boolean output, `light`, and two states.
Body text is set in Atkinson Hyperlegible Next at 18 px, at most about 75 characters to the line; inline code such as
`pre(I)`, `l`, `O = 0` and `if A go to B` uses Atkinson Hyperlegible Mono, so `I`, `l` and `1` stay apart.

## A section heading

Paragraphs keep a comfortable measure even where the column is wider, because widgets use the full
width of the column. **Strong text** is set in the ink colour, *emphasis* in italics, and
[links](/learn/ticks/) in the accent colour, KIELER's keyword plum.

### A subsection heading

- A tick is one reaction of the whole chart.
- Lists use muted markers, so the text leads.
- Nested structure stays shallow in a beginner's guide.

1. Ordered lists are for real sequences.
2. Their numbers use tabular figures.

#### A minor heading

Use minor headings sparingly; most chapters need only `##` and `###`.

## Code

```sctx title="toggle.sctx" {5}
scchart Toggle {
  input bool button
  output bool light = false

  initial state Off
    if button do light = true go to On

  state On
    if button do light = false go to Off
}
```

A snippet that is not a whole chart (the fence may also say `sct`):

```sct
state Waiting
  immediate if A && !B do count++ go to Done
  if pre(S) abort to Error   // strong abort
```

## Check your understanding

<Quiz
  question="In tick 1, `button` is true. Which state is `Toggle` in after the tick?"
  options={['`Off`: the transition is delayed, so it cannot fire in the tick `Off` is entered', '`On`: `button` is true, so the transition fires', 'Neither: the chart has not started yet']}
  answer={0}
>
Tick 1 enters the initial state. A delayed transition is checked from the next tick on, so `Toggle` stays in
`Off` whatever `button` is. KIELER's simulation shows the same.
</Quiz>

<KeyIdeas>
- A chart reacts in ticks: inputs are read, the chart reacts, outputs are written.
- A delayed transition cannot fire in the tick its source state was entered.
- Inputs keep their value until they are changed.
</KeyIdeas>
