This page exercises every widget of the guide, including the awkward cases. The Playwright checks in
`tests/widgets/` drive it.

By hand: the simulations load their code only when you first point at, touch or tab into one (`client:engage`;
a click before that is replayed). With the keyboard, Tab into a diagram and use the arrow keys: each state and
transition is focused in turn, with a ring, and its source lines are marked in the **Both** view; Tab on to the
code lines (Up and Down), the controls, the timing diagram (Left and Right go back and step) and the "What
happened" lines (Up and Down: each marks its elements). Print the page (or its print preview): diagrams, code
and the guided tours as text, no controls, in the light theme.
